== Preface

This chapter describes the RISC-V trace architecture.
It contains the following version of the RISC-V trace module,
which has been ratified:

[%autowidth,float="center",align="center",cols="^,<",options="header",]
|===
|Module |Version
|Efficient Trace (E-Trace) |2.0.2
|===

The Efficient Trace for RISC-V specification was authored by Gajinder
Panesar and Iain Robertson.
