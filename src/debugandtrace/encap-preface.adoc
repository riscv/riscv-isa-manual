== Preface

This chapter describes the RISC-V encapsulation format for unformatted
trace and diagnostic data.
It contains the following version of the RISC-V encapsulation module,
which has been ratified:

[%autowidth,float="center",align="center",cols="^,<",options="header",]
|===
|Module |Version
|Unformatted Trace & Diagnostic Data Packet Encapsulation |1.0.0
|===
